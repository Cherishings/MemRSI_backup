M=/data/share/ext_songzhiying/PAOS-MemRSI-migration-20261022
All defaults use the existing M tree. Override PAOS_MIGRATION_ROOT only if needed.

  Popen(policy_command(20502), env=lane_env(2, 'policy'), ...)

    "$M/conda-envs/paos-policy/bin/python" /DEPLOY/runtime/policy_entry.py \
    --port 20502 --checkpoint "$M/models/pi05_libero"

Worker under M/conda-envs/paos-agent/bin/python:
  import sys
  sys.path.insert(0, '/DEPLOY/runtime')
  import runtime_adapter
  wiring = runtime_adapter.configure(2, 20502)
  import feedback_workflow
  result = await feedback_workflow.run(args)
  # args.port must equal the lane's 20502.
  # Root coordinator owns GPU leases, process groups, and time/stop budgets.

configure(gpu, port, core_path=None) accepts a core_path containing PhyAgentOS/,
not the workflow source path. Default is M/PhyAgentOS-core.
